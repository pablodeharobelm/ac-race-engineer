# AC Race Engineer

AC Race Engineer is a telemetry, vehicle dynamics and AI-assisted race engineering platform for Assetto Corsa.

## Project goals

The project aims to collect, process and analyse vehicle telemetry to provide useful information about:

- Tyres
- Brakes
- Suspension
- Vehicle dynamics
- Driver inputs
- Track conditions
- Car setup
- Session behaviour

The platform will progressively incorporate Data Engineering, Machine Learning and AI techniques to assist the driver with race engineering decisions and setup recommendations.

## Planned technologies

- Python
- SQL
- PostgreSQL
- Parquet
- Docker
- Apache Kafka
- Apache Spark
- PySpark
- Airflow
- Machine Learning
- Databricks
- Azure
